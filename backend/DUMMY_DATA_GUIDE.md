# 더미 데이터 초기화 안내

## 실행 방법

`src/main/resources/application.yml`에 다음 설정이 들어 있습니다.

```yaml
app:
  seed-sample-data: true
```

백엔드를 실행하면 `AdminInitializer`가 기본 관리자 계정을 먼저 준비하고, 이후 `DummyDataInitializer`가 더미 데이터를 추가합니다.

더미 데이터 생성을 중단하려면 `seed-sample-data`를 `false`로 변경하세요.

## 생성 목표 수량

- 일반 회원: 최소 120건
- 공지사항: 최소 100건
- 자료실: 최소 100건
- Q&A: 최소 120건
- 자료실 추가 요청: 최소 100건
- 교통서비스: 최소 100건
- 열차: 최소 100건
- 일별 대시보드 통계: 최소 100일분

관리자와 노선/역 정보는 대량 생성하지 않습니다. 기존 데이터도 삭제하지 않습니다. 각 테이블이 목표 수량 이상이면 해당 테이블에는 추가하지 않고, 목표 수량 미만이면 부족한 수량만 채웁니다.

## 테스트 계정

- 일반 회원 로그인 ID: `demo_member_001`, `demo_member_002` ...
- 일반 회원 공통 비밀번호: `Demo1234!`
- 관리자 계정은 `application.yml`의 `app.admin.*` 설정을 사용합니다. 기본 설정에서는 ID `admin`, 비밀번호 `admin1234!`입니다.

회원 비밀번호는 BCrypt로 인코딩하여 저장합니다.

## 참고

- 이 데이터는 화면과 API 시연을 위한 가상 데이터입니다. 실제 운영 정보로 사용하지 마세요.
- 첨부파일 테이블은 실제 파일이 없는 상태에서 가짜 파일 경로가 생기는 것을 피하기 위해 자동 생성하지 않습니다.
- Figma 링크는 이 실행 환경에서 프레임 내용을 직접 불러오지 못해, 현재 백엔드 도메인과 7호선 교통서비스 관리 맥락을 기준으로 제목과 본문 예시를 구성했습니다. 화면별 문구를 정확히 맞추려면 해당 Figma 프레임을 PNG로 내보내거나 캡처해 추가로 전달해 주세요.
